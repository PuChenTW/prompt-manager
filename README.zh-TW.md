# Prompt Manager

輕量級 Chrome 擴充功能，用於管理 AI 提示詞模板，支援快速插入、自動變數偵測與游標定位。

## 核心功能

### 1. 提示詞管理

**建立與儲存提示詞**
- 建立可重複使用的提示詞模板，包含標題與內容
- 支援使用 `{{variable}}` 語法的變數占位符
- 字元限制：標題 200 字元，內容 100,000 字元
- 使用 IndexedDB 持久化儲存，支援超大型模板

**編輯與刪除**
- 點擊任意提示詞卡片即可編輯
- 即時字元計數器，附視覺化回饋
- 編輯器中 `{{variable}}` 占位符的語法高亮
- 拖放排序提示詞

**視覺化管理**
- 現代卡片式 UI，具備毛玻璃效果
- 懸停動畫與流暢過渡效果
- 內容預覽，自動截斷（最多 3 行）
- 大型提示詞集合的可捲動列表

### 2. 提示詞插入

#### 方法 A：右鍵選單
1. 在任意可編輯欄位（文字區域、輸入框、contenteditable）上按右鍵
2. 從右鍵選單選擇 **Prompt Manager**
3. 從子選單選擇提示詞
4. 提示詞立即插入

#### 方法 B：鍵盤快捷鍵（指令面板）
1. 聚焦在任意可編輯欄位
2. 按下觸發鍵（預設：`Ctrl+/`）
3. 搜尋面板出現，支援模糊搜尋
4. 輸入文字以依標題或內容篩選提示詞
5. 使用 `↑`/`↓` 方向鍵導航，按 `Enter` 插入，按 `Esc` 關閉

**模糊搜尋功能：**
- 不區分大小寫的比對
- 同時搜尋標題與內容
- 在搜尋結果中高亮顯示匹配文字
- 鍵盤優先操作

### 3. 自動變數處理

**智慧游標定位**
- 插入後，自動偵測第一個 `{{variable}}` 占位符
- 將游標移至該變數並選取
- 可立即輸入以取代該變數
- 支援標準輸入框與 contenteditable 元素

**支援的輸入類型：**
- `<textarea>` 元素
- `<input>` 文字欄位
- `contenteditable` 元素（ChatGPT、Claude、Notion 等）

### 4. 可自訂快捷鍵

**設定方式：**
- 在選項頁面點擊齒輪圖示（⚙️）
- 點擊輸入欄位開始錄製
- 按下您想要的按鍵組合
- 僅允許組合鍵（例如 `Ctrl+K`、`Cmd+Shift+P`）
- 單鍵觸發因安全考量被封鎖

**預設快捷鍵：** `Ctrl+/`

**驗證規則：**
- 防止單鍵觸發以避免誤觸
- 至少需要一個修飾鍵（Ctrl、Alt、Cmd、Shift）
- 無效按鍵組合的視覺化回饋

## 技術實作

### 架構

**Manifest V3 合規**
- Service Worker 背景腳本
- 在所有 URL 注入內容腳本
- 最小化權限（storage、contextMenus）

**各元件：**
- `background.js` — 管理右鍵選單的 Service Worker
- `content.js` — 負責快捷鍵偵測與提示詞注入的內容腳本
- `options.js` — 提示詞 CRUD 操作的選項頁面邏輯
- `options.html/css` — 現代化提示詞管理 UI
- `panel.css` — 指令面板浮層的樣式

### 注入機制

**文字插入策略：**
1. 偵測目前的輸入元素（最後聚焦或右鍵點擊的）
2. 對標準輸入框/文字區域：
   - 使用直接的 value 操作與選取位置定位
3. 對 contenteditable 元素：
   - 使用現代 Selection API 與 `insertNode()` 進行精確插入
   - 處理複雜 DOM 結構（ChatGPT、Claude 等）
   - 觸發 `input` 事件以相容 React/Vue

**變數偵測：**
- 正則表達式模式：`/\{\{[^}]+\}\}/g`
- 在 contenteditable 元素中向後搜尋文字
- 向前走訪演算法以計算確切游標位置
- 自動選取以便立即取代

### 儲存架構

- **提示詞：** 儲存在 **IndexedDB**（`PromptManagerDB`），突破 Chrome 儲存空間的典型 5MB 限制，允許理論上無上限的大型提示詞模板。
- **設定：** 快捷鍵設定（`triggerConfig`）保留在 `chrome.storage.local`，便於快速輕量存取。

**IndexedDB 格式：**
```json
{
  "id": "1705392847123",
  "title": "程式碼審查提示詞",
  "content": "審查這段 {{language}} 程式碼：\n\n{{code}}\n\n重點關注：\n1. 效能\n2. 安全性\n3. 最佳實踐"
}
```

## 使用範例

### 範例 1：財務分析提示詞
```
標題：財務分析師
內容：扮演財務分析師的角色。分析以下資料：{{data}}

請提供以下洞察：
1. 關鍵趨勢
2. 風險因素
3. 投資建議
```

**工作流程：**
1. 在 ChatGPT 輸入框右鍵 → 選擇「財務分析師」
2. 游標自動選取 `{{data}}`
3. 貼上您的財務資料
4. 提交給 AI

### 範例 2：程式碼審查模板
```
標題：程式碼審查員
內容：審查這段 {{language}} 程式碼，重點關注：
- 程式碼品質
- 效能問題
- 安全性漏洞
- 最佳實踐

程式碼：
{{code}}
```

**工作流程：**
1. 在任意文字欄位按 `Ctrl+/`
2. 輸入「code」進行篩選
3. 按 `Enter` 插入
4. 輸入程式語言名稱（如「Python」）
5. Tab 或點擊移至下一個變數，貼上程式碼

### 範例 3：電子郵件模板
```
標題：專業電子郵件
內容：主旨：{{subject}}

親愛的 {{recipient}}，

{{body}}

敬上，
{{sender}}
```

## 安裝方式

### 從原始碼安裝
1. 複製此儲存庫
2. 開啟 Chrome 並前往 `chrome://extensions/`
3. 啟用「開發人員模式」（右上角切換按鈕）
4. 點擊「載入未封裝項目」
5. 選擇專案目錄
6. 工具列中出現擴充功能圖示

### 首次設定
1. 點擊擴充功能圖示以開啟選項頁面
2. 點擊「新增提示詞」建立您的第一個模板
3. （選用）點擊齒輪圖示自訂快捷鍵
4. 開始透過右鍵選單或快捷鍵使用提示詞

## 瀏覽器相容性

- **Chrome：** 完整支援（Manifest V3）
- **Edge：** 完整支援（基於 Chromium）
- **Brave：** 完整支援
- **Opera：** 完整支援
- **Firefox：** 不支援（需要 Manifest V2 適配）

## 限制

1. **變數導航：** 僅自動選取第一個 `{{variable}}`，後續變數需手動導航。
2. **iframe 支援：** 複雜的巢狀 iframe 可能需要額外處理。
3. **儲存限制：** 感謝 IndexedDB 遷移，儲存空間實際上無限制（受限於瀏覽器配額）。
4. **Contenteditable 複雜性：** 部分高度客製化的編輯器可能存在邊界情況。

## 隱私與安全

- **無網路請求：** 所有資料均儲存在本地
- **無數據分析：** 零追蹤或遙測
- **無外部依賴：** 純 Vanilla JavaScript
- **最小化權限：** 僅存取 storage 與右鍵選單
- **開源：** 完整程式碼透明公開

## 開發

### 檔案結構
```
prompt-manager/
├── manifest.json          # 擴充功能設定
├── background.js          # Service Worker（右鍵選單、資料庫遷移）
├── content.js             # 內容腳本（注入邏輯、訊息傳遞）
├── db.js                  # IndexedDB 封裝操作
├── options.html           # 選項頁面 UI
├── options.js             # 選項頁面邏輯
├── options.css            # 選項頁面樣式
├── panel.css              # 指令面板樣式
└── icons/                 # 擴充功能圖示（16、32、48、128）
```

### 關鍵函式

**content.js：**
- `showPanel()` — 顯示指令面板
- `injectIntoActiveElement()` — 將提示詞插入目前欄位
- `focusVariable()` — 自動選取第一個變數
- `fuzzyMatch()` — 用於篩選的搜尋演算法

**options.js：**
- `renderPrompts()` — 渲染含拖放功能的提示詞列表
- `startEdit()` — 開啟編輯視窗
- `deletePrompt()` — 附確認的提示詞刪除
- `applyHighlights()` — 變數的語法高亮

**background.js：**
- `getPrompts`（內容腳本）與 `updateMenus` 的訊息監聽器
- 自動初始遷移：從 local storage 遷移至 IndexedDB
- `createMenus()` — 建構右鍵選單結構
- 右鍵選單點擊處理器，用於提示詞注入

## 效能

- **輕量：** 總大小約 30KB
- **快速注入：** 大多數提示詞不到 10ms
- **高效搜尋：** 模糊比對優化至 100ms 內
- **低記憶體佔用：** 記憶體使用量低於 5MB
- **無背景處理：** 僅在需要時啟動

## 疑難排解

**快捷鍵無法使用：**
- 檢查是否有其他擴充功能使用相同快捷鍵
- 確認快捷鍵為組合鍵（非單一字元）
- 更改設定後重新載入擴充功能

**提示詞未插入：**
- 確保目標欄位已聚焦或已被右鍵點擊
- 嘗試在使用快捷鍵前先點擊該欄位
- 檢查瀏覽器主控台是否有錯誤（F12）

**變數未自動選取：**
- 確認變數使用 `{{variable}}` 語法（雙大括號）
- 某些 contenteditable 元素可能不支援選取
- 嘗試使用 Tab 手動導航至變數
